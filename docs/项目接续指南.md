# 项目接续指南（Pek.ZDsMallUI · Zig）

## 一句话

把「猿人易 / NCube / DsMallUI」后台 UI 能力（UEditor 后端、上传下载、后台 Area、视图约定）
以 **与 C# 同构的目录与路由** 落到 Zig，复用 `zzig` 的 Web 栈。

## 常用命令

```powershell
zig build test                       # 单元测试（基线 82 项）
zig build                            # 构建示例 → zig-out/bin/zdsmallui-admin.exe
zig build run                        # 默认 127.0.0.1:18080，区域 Biz
zig build run -- 18081 Admin         # 端口 + 区域名
.\tools\regression.ps1               # 一键回归（构建 → 测试 → HTTP 冒烟），退出码 0/1
.\tools\regression.ps1 -SkipSmoke    # 只跑构建与测试
.\tools\sync-wwwroot.ps1             # 从 C# 参考工程同步第三方静态资源
```

## 目录约定（与 C# 同构）

| C# | Zig |
|---|---|
| `Areas/Admin/Controllers/ConfigController.cs` | `Areas/Admin/Controllers/ConfigController.zig` |
| `Areas/Admin/Views/Config/Index.cshtml` | `Areas/Admin/Views/Config/Index.cshtml` |
| `Controllers/UploadController.cs` | `Controllers/UploadController.zig` |
| `Views/Shared/Prompt.cshtml` | `Views/Shared/Prompt.cshtml` |
| `Models/Hierarchy.cs` | `src/models.zig` |
| `PekStartup.cs` | `src/options.zig`（`DsMallUi` / `Builder`） |
| `UEditor/*.cs` | `src/ueditor/*.zig` |
| `ueconfig.json` | `assets/ueconfig.json` |

**Zig 特有**：`pek_zdsmallui.zig`（模块根，必须放仓库根才能覆盖 `src/`、`Areas/`、`Views/`、`assets/`）、
`src/multipart.zig`（zzig 暂无多段表单解析）、`src/password.zig`（C# 口令互通）。

## 装配与生命周期

```zig
const ui = try pek_zdsmallui.DsMallUi.builder(gpa, io).adminArea("Biz").build();
defer ui.deinit();
_ = try ui.materializeDefaults();      // 只补缺失：视图 + ueconfig.json + admin-config.js
var app = try zzig.web.App.init(gpa, io, .{ .wwwroot = "wwwroot" });
defer app.deinit();
try ui.mount(&app);
try app.run("127.0.0.1", 18080, .{ .max_body = ui.maxUploadBytes() });
```

**`DsMallUi` 必须堆分配、挂载后不得移动**：控制器（`zzig.web.Controller`）保存指向它的指针。

## 关键实现坑（都已踩过）

1. **zig 的 `@import` / `@embedFile` 不能跨模块根目录** → 模块根文件必须在仓库根（`pek_zdsmallui.zig`）。
2. **zzig 中间件只在命中路由或设了 fallback 时执行** → `/Upload/downloads/{多层路径}` 必须走
   `app.router.fallback`（顺序：上传目录下载 → wwwroot 静态 → 404）。
3. **Razor 子集 `@section` 体内遇到 `}` 就结束** → 内联 JS 全部移到静态文件（`assets/admin-config.js`）。
4. **`@if` 条件必须是布尔值**；模型里缺键会渲染失败 → `views.withTemplateDefaults` 先补齐。
5. **Zig 0.17 的格式化填充** `{d:0>2}` 会输出 `+2026` → 用 `appendPadded` 手工补零。
6. **随机数走 `std.Random.IoSource{ .io = io }`**（`std.crypto.random` 在 0.17 已移除）。
7. **入口是 `pub fn main(init: std.process.Init) !u8`**，参数用 `std.process.Args.Iterator.initAllocator`。

## 回归门槛

- `zig build test` 全绿（当前 **82** 项）；新增用例后同步抬高 `tools/regression.ps1` 的基线；
- `tools/regression.ps1` 退出码 0 才算交付；报告在 `artifacts/regression/report-*.txt`；
- 冒烟覆盖：三个页面、UEditor 配置、multipart 上传、列表、下载（含 `Content-Disposition`）、
  保存设置回读、登录 302 / 失败 200、未支持动作。
