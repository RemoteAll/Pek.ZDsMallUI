# 项目记忆（Pek.ZDsMallUI · Zig）

> 本文件同时是「跨电脑可接续」的镜像：由 `tools/continuity/sync-memory.ps1` 与本机 repo 记忆双向同步。
> **正文只用 `###` 及更低级标题**（`sync-memory.ps1` 按行首 `## ` 切分章节，会拆碎镜像）。

### 架构

- 模块根 `pek_zdsmallui.zig` **必须在仓库根**：Zig 的 `@import`/`@embedFile` 不能跨模块根目录，
  而 C# 同构目录把代码放在 `Areas/`、`Views/`、`assets/`（都在 `src/` 之外）。
- 目录：`Areas/Admin/Controllers/{AdminArea,HomeController,ConfigController,LoginController}.zig`、
  `Controllers/UploadController.zig`、`Areas/Admin/Views/**`、`Views/Shared/**`、`src/**`。
- 控制器动作签名统一 `fn (self: ?*anyopaque, c: *zzig.web.router.Ctx) !ActionResult`，
  `self` 一律是 `*AdminArea`（区域共享上下文：backend / views / area / home / upload_prefix）。
- 视图统一由 `src/views.zig` 的 `Views`（单一 `zzig.web.ViewRenderer`，带模板缓存）渲染，
  控制器**不**用 `Controller` 自带的渲染器（避免每控制器一份缓存）。

### 实测坑（Zig 0.17）

- `@import`/`@embedFile` 跨模块根 → `error: import/embed of file outside module path`；模块根放仓库根即可。
- `std.crypto.random` 已移除 → 用 `std.Random.IoSource{ .io = io }.interface()`（需 `io`）。
- `std.process.argsAlloc` / `getCwdAlloc` 已移除 → `pub fn main(init: std.process.Init) !u8` +
  `std.process.Args.Iterator.initAllocator`；路径用 `std.Io.Dir.cwd().realPathFileAlloc(io, ".", alloc)`。
- 格式化填充 `{d:0>4}` 会输出 `+2026` → 手工补零（`path.appendPadded`）。
- `@embedFile` 的路径按模块根 + 相对文件；`src/views.zig` 用 `../Areas/...`、`../Views/...` 正常。
- `b.args` 已移除 → `run_exe.addPassthruArgs()`。

### zzig 行为

- `web.App` 的中间件**只在命中路由或设置 fallback 时执行**；`/Upload/downloads/{深路径}` 必须用
  `app.router.fallback`（本仓库顺序：上传目录 → `app.statics` → 404）。
- `ViewRenderer` 原生支持 `Areas/{Area}/Views/{Controller}/{View}.cshtml` + `setFallbackArea("Admin")`；
  布局名含 `/`（`Shared/_Layout`）会先试 `Areas/{Area}/Views/Shared/...`，再试 `Views/Shared/...`。
- `StaticFiles` 磁盘文件默认**流式**发送（`Response.file`），加头要自己拼 `headers`。
- `StaticFiles` 的 ETag 是弱 ETag（`W/"size-mtime"`），条件请求 304 已由库测试覆盖。

### Razor 子集（zzig view）

- 支持 `@expr`、`@if/else`、`@foreach`、`@{ var x = ...; Layout = "..."; }`、
  `@section` + `@await RenderSectionAsync`、`@Html.PartialAsync`。
- **`@section` 体内遇到 `}` 即结束** → 内联 JS 一律外置（`assets/admin-config.js`）。
- `@if` 条件必须布尔值；取不到属性是硬错误 → `views.withTemplateDefaults` 先补默认键。
- 编码：只转义 `& < > " '`，中文原样输出（与 Rust 的 `&#x..;` 实体不同）。

### 口令与安全

- `src/password.zig` 复刻 C# `SaltPasswordProvider`：`$算法$盐$散列`，默认 **`md5+sha1`**；
  五种算法全支持；旧式明文/MD5 十六进制可验证并自动升级；`md5+sha1` 分支兼容「前端先 MD5」。
- 上传：扩展名白名单（`ueconfig` 的 `*AllowFiles`，空 = 全拒）→ 体积上限（配置与全局取小）
  → 路径格式化（`sanitizeFileName` 折叠 `..`）→ 越界校验 → 落盘。
- 抓取：只允许 http/https，20 秒超时（`zzig.Http.fetchBytesWithTimeout`），最多 10 个来源。
