## 2. 行为差异（均为「补实现 / 修正」）

1. **上传真的会落盘**：C# `UploadHandler.Process` 全部注释（永远「未知错误」）、
   `UeditorConfig.GetStringList` 返回空（白名单恒空）。
2. **抓取远程图片**：C# `Crawler.Fetch` 注释掉；Zig 实现下载并落盘，**只允许 http/https**。
3. **`{rand:n}` 位数**：C# 实际产出 n+1 位；Zig 按官方实现产出 n 位。
4. **文件名清洗**：非法字符 → `_`、`..` → `__`，并做落盘越界二次校验。
5. **扩展名归一化**：`ueconfig` 里 `"webp"` 这类缺前导点的值统一补点小写。
6. **后台持久化**：`AdminBackend`（Zig vtable）注入，不绑定 ORM。
7. **口令**：Zig 默认 `md5+sha1`（C#/Rust `dhrust` 默认 `sha512`），
   理由见 `docs/决策记录.md`；验证兼容全部五种算法与旧式明文/MD5。
8. **抓取扩展名**：Zig 按 URL 推断（无响应头可用），无扩展名 `.jpg` 兜底；换来 20 秒超时保护。
9. **登录 / 退出与 JWT**：C# 参考工程只声明了 `[EntityAuthorize(PermissionFlags.Update)]`，
   `PekStartup.cs` 里 `UseAuthentication` / `UseAuthorization` 也是注释掉的；Zig 侧把签发、
   校验、登出吊销补完整（复用 `Pek.ZPermissions`，与 C#/Rust 字节级互通），
   并同时支持 Cookie（浏览器）与 `Authorization: Bearer`（脚本）。
10. **版式：复用参考工程 `admin.css`**（不自造皮肤）——视图 DOM 与类名与 C# 一致：
    `.page/.fixed-bar/.item-title/.subject/.tab-base`、`.ncap-form-default > dl > dt + dd > input.input-txt`、
    `.explanation`、登录页 `.login/.login_body/.login_header/.login_content/.form-group/.text/.btn`。
    曾自造过一套 `admin-*` 皮肤（`admin-ui.css`），因与参考完全不一致被废弃。
11. **登录页验证码**：C# 登录页有 `checkcode`（图形验证码），Zig 侧当前没有验证码后端，
    表单不渲染该字段；接入验证码服务时再补（不得用假占位）。

## 3. 视图：C# Razor → Razor 子集（zzig）

| 支持 | 不支持（需改写） |
|---|---|
| `@expr`、`@(expr)`、`@@`、`@* *@` | `@using`、`@inject`、`@functions`、`@helper` |
| `@if / else if / else`、`@foreach`、`@{ var x = ...; }` | `@switch`、`@while`、LINQ/lambda/方法链 |
| `@{ Layout = "..." }`、`@RenderBody()`、`@section`、`@await RenderSectionAsync` | `Layout = null`（不声明 Layout 即独立页面） |
| `@await Html.PartialAsync("Name", model)` | tag helper（`asp-append-version` 等） |

由此产生的改写：

- `@PekHtml.GenerateCssFiles()` / `@T("...")` / `@inject` → 写死静态资源路径与中文文案；
- `ViewBag.*` → 统一走 `@Model.*`（控制器组装一个 JSON 模型）；
- **属性取不到即渲染失败** → `views.withTemplateDefaults` 先补齐内置模板引用到的全部键；
- **`@{ // 注释 }` 不可用** → 改 `@* … *@`；
- **`@section` 体内 `}` 会结束块** → 内联 JS 移到 `wwwroot/static/admin/js/admin-config.js`；
- 隐式输出只转义 `& < > " '`，中文原样输出。

## 5. 复用检索证据（写码前）

```powershell
# UEditor：Zig 侧无实现
Get-ChildItem 'G:\Code\Zig' -Recurse -File -Include *.zig |
    Select-String -Pattern 'ueditor|UEditor' -List        # → 无命中

# multipart：zzig 只解析 application/x-www-form-urlencoded
Select-String -Path 'G:\Code\Zig\zzig\src\http\*.zig' -Pattern 'multipart|boundary='   # → 无命中

# 口令互通：Zig 侧无 SaltPasswordProvider
Get-ChildItem 'G:\Code\Zig' -Recurse -File -Include *.zig |
    Select-String -Pattern 'SaltPassword|md5\+sha1' -List  # → 无命中
```

结论：UEditor、multipart、C# 口令互通无既有实现，在本仓库落地；
HTTP/路由/控制器/视图引擎/静态资源/日志/文件/时间/出网客户端/随机数全部复用 `zzig`。
若出现**第二个**需要 multipart 的消费方，按约定把 `src/multipart.zig` 上收进 `zzig.http`。
