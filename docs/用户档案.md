# 用户档案（项目视角）

## 偏好（本仓库相关）

- **中文交流**；汇报只写结论 + 证据（`文件:行号` / 退出码 / 实测数字），不复述工具已展示的原文。
- **目录要跟 C# 一致**：C# 有 `Areas/`、控制器一文件一类；Zig 侧照做
  （用户原话：「每个控制器一个zig文件吧，和C#一样的」、「我记得C#的区域是会有Area这种文件夹的」）。
- **复用优先**：写码前先检索公共库（本仓库对应 `zzig`）→ 兄弟项目 → 本仓库既有实现。
- **验证分档**：`zig build test` → `zig build` → 起本地实例实测；不打无谓的全量包。
- **禁止原生弹窗**（`alert`/`confirm`/`prompt`）；危险操作要有明确语义。
- **口令规范**：存储走统一算法（本仓库默认 `md5+sha1`，与 C# 字节级互通），
  后端同时接受明文与「前端先 MD5」；不引入自写散列。

## 工具链事实（本机实测）

- Zig：`zig version` = **0.17.1**（WinGet 安装）；`zig env` 可查 `lib_dir`。
- zzig 以路径依赖引入：`build.zig.zon` 写 `.zzig = .{ .path = "../zzig" }`。
- 本机 PowerShell 5.1：终端显示中文会乱码（控制台编码），**文件本身是 UTF-8**；
  验证中文请按 UTF-8 解码后再断言（`[Text.Encoding]::UTF8.GetString($bytes)`）。
